## 1. 서론

- 목표: 정상 이미지만으로 산업 이미지의 이상 유무와 이상 위치를 찾는 SimpleNet을 재현함.
- SimpleNet은 사전학습 CNN 특징에 작은 가우시안 잡음을 더해 가짜 이상 특징을 만들고, 정상 특징과 구분하는 판별기를 학습함 [1].
- 기존 memory 기반 방법은 테스트 patch와 normal memory를 검색함. SimpleNet은 판별기 점수를 사용한다는 차이가 있음.

## 2. 사전 지식과 문제 정의

### 기술 용어

- *I-AUROC*: 이미지 전체 이상 점수로 정상·이상 이미지를 구분하는 성능. 1에 가까울수록 좋음.
- *P-AUROC*: 픽셀별 이상 지도와 정답 mask를 비교하는 위치 찾기 성능. 1에 가까울수록 좋음.

### 표기법

| 표기법 | 설명 |
|---|---|
| `x` | 입력 이미지 |
| `Fφ(x)` | ImageNet 사전학습 특징 추출기가 만든 지역 특징 |
| `Gθ` | 특징 adapter |
| `Dψ` | 정상 특징과 가짜 이상 특징을 구분하는 판별기 |

### 정의

정의 1. 최종 범주 score.
공식 코드가 40개 meta epoch 중 가장 높은 image AUROC checkpoint에서 저장한 I-AUROC, P-AUROC를 말함.

### 문제 정의

문제 1. SimpleNet MVTec AD 재현.
정상 train 이미지만 주어질 때, 각 테스트 이미지의 이상 점수와 픽셀 이상 지도를 예측함. 성공 기준은 15개 범주 평균 I-AUROC와 P-AUROC가 논문 보고값 [1]에 얼마나 가까운지임.

## 3. 관련 연구

- PatchCore [3]: 정상 patch 특징을 normal memory로 저장하고 테스트 patch와의 최근접 거리를 이상 점수로 사용함.
- SimpleNet [1]: 정상 특징에 Gaussian noise를 더한 가짜 이상 특징과 정상 특징을 판별하도록 학습함. 추론에서 normal memory 최근접 검색을 사용하지 않음.
- 데이터셋: MVTec AD [2]의 5개 texture와 10개 object 범주를 사용함.

## 4. 선택한 방법 또는 절차

- 공식 구현체 revision `351a2b8d4e8cfc944dbccbf9bc6ceda930c6f26b` 사용.
- WideResNet-50-2 `layer2`, `layer3`, feature dimension 1,536 사용.
- 논문 명시 설정: resize 256, crop 224, batch 4, noise standard deviation 0.015, 40 meta epochs, meta epoch당 discriminator 4회 학습.
- adapter는 bias 없는 FC로 두고 Adam learning rate 0.0001, weight decay 0.00001을 사용함.
- 실행 스크립트: [run_simplenet_mvtec_paper_protocol_wsl.sh](../method2/source/run_simplenet_mvtec_paper_protocol_wsl.sh).

## 5. 실험

### 질문과 가설

- 질문: 논문 본문 조건을 반영한 공개 구현체가 MVTec AD 15개 평균을 논문에 가깝게 재현하는가?
- H1: I-AUROC와 P-AUROC가 논문 평균에서 각각 1.0%p 이내일 것임.

### 설정

- 데이터: MVTec AD 15개 범주, 각 범주의 정상 train 이미지만 사용.
- metric: I-AUROC, P-AUROC. seed 0, data loader workers 2.
- raw result: [SimpleNet_MVTecAD_WR50_paper_protocol_results.csv](../method2/source/results/SimpleNet_MVTecAD_WR50_paper_protocol_results.csv).

## 6. 논의

- H1은 지지됨. 두 지표 모두 논문 평균에서 1.0%p 이내임.
- 논문 조건을 반영한 결과가 초기 공식 코드 기본 설정 기준선보다 낮아, 공식 코드 기본값과 논문 본문 설명이 완전히 같은 protocol이 아닐 가능성을 확인함.
- 아직 주장할 수 없는 것: 논문 작성 환경까지 포함한 bitwise 동일 재현.
- 남은 불확실성: 단일 seed, 최신 라이브러리 호환 수정, category별 편차임. 특히 `wood` P-AUROC 91.08%, `screw` I-AUROC 95.29%가 평균을 낮춤.
