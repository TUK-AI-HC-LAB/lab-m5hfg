# W47 Simple3D 캡슐 — STEP 기반 FPFH 120-NN 비교

## 바꾼 부분

[Wang & Ino, STEP, JPDC 207 (2026)](https://doi.org/10.1016/j.jpdc.2025.105187)의 **Indexing STEP**을 참고해 FPFH용 이웃 탐색 구간만 별도로 구현함. 찾을 수 있는 공개 공식 코드는 확인하지 못했으므로 저자 구현 재현이 아님.

1. 원본 점을 GPU K-means로 512개 군집으로 묶음(50회 갱신). 군집마다 중심과 모든 소속 점을 덮는 반경을 구함.
2. 각 질의점에서 해당 군집 안 점까지의 최소 가능 거리를 계산해 가까울 가능성이 큰 군집부터 확인함.
3. 현재 120번째로 가까운 점보다 더 가까운 점이 나올 수 없는 나머지 군집은 건너뜀. 이 구현에서는 GPU 스레드 블록과 비토닉 정렬로 후보를 갱신함. 동일 거리면 원본 인덱스가 작은 점을 앞에 놓음.

논문의 정확한 저차원 탐색 원리만 구현함. 저자 커널 구성, 고차원 전체 탐색 자동 전환은 재현하지 않음. **FlashFPS, 특징 집계 128-NN, 기존 법선, FPFH 40·80·120의 계산식은 변경하지 않음.** FlashFPS 자체는 두 방법에 공통인 단계이므로 이 구간 실험에서는 실행·계측하지 않았음.

## 결과

RTX 5080에서 기존 테스트 목록과 일치하는 MiniShift 캡슐 **5개(정상 2개, 이상 3개)**, 샘플당 원본 50만 점을 비교함. 두 방법은 같은 GPU 좌표를 사용하고 실행 순서를 번갈아 측정함. 자료구조 구축, 정확한 120-NN 조회, 원본 행 순서의 INT32 인덱스 출력까지 포함함. 별도 예열 후 측정했고, CPU 입력 로딩·법선·FPFH 검증 시간은 표에서 제외함.

| 평균 (ms/샘플) | CuPy GPU KD-tree | STEP 기반 | 차이 (STEP − KD-tree) |
|---|---:|---:|---:|
| 트리 / 군집 인덱스 구축 | 17.02 | 334.10 | +317.08 |
| FPFH용 120-NN 조회 | 1,127.20 | 302.05 | −825.15 |
| **두 단계 합계** | **1,144.22** | **636.15** | **−508.06 (−44.40%)** |

5개 모두 구축을 포함해 빨랐음. 합계 기준 기존 시간이 STEP 기반의 약 1.80배였음. 차이는 반올림 전 값으로 계산함.

| 동일성 검사 | 결과 |
|---|---|
| 1,024개 합성점, 전수 거리 비교 | 120-NN 목록이 정확히 일치 |
| 캡슐 5개, 250만 조회 행 | 120개 이웃 **집합** 불일치 0행, **순서** 불일치 71행. 거리 제곱을 다시 계산한 뒤 정렬해서 비교한 최대 차이 0 |
| 실제 FPFH 40·80·120 | 40에서 40행(최대 절대 차이 2.59451), 80에서 84행(1.32683), 120에서 0행 차이. 40·80의 차이는 동일한 정상 샘플 1개에서 발생 |

**판단: 속도 개선 후보. 동일 결과를 내는 교체로는 아직 보류.** 120개가 같은 집합이어도, 같은 거리에 있는 점의 순서가 다르면 앞 40·80개 목록이 달라질 수 있음. 다음에는 스케일 경계의 동점 여부와 각 스케일의 이웃 목록을 대조하고, 동점 처리를 통일하거나 예외 행만 기존 조회로 복구하는 방식을 비교할 것. 이번 결과는 이웃 탐색 구간의 파일럿이며 **전체 추론, AUROC/AP, 최대 VRAM은 측정하지 않음**.
