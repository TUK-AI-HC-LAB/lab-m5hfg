# W49 Simple3D — GPU 후보 탐색 1차 보간의 다른 점군 및 실행 순서 검증

**결과:** 변경판을 먼저 실행한 캡슐에서도 전체 추론이 **6.43%** 짧았음. Anomaly-ShapeNet vase9에서는 전체 추론이 **2.75%** 짧았음. 두 새 비교 모두 점별 점수·물체 점수·메모리뱅크·AUROC/AP 동일.

## 비교 조건

- RTX 5080. 캡슐 정상 54개·테스트 130개(점군당 50만 점); vase9 정상 4개·테스트 37개(평균 약 12.3만 점). 쌍마다 동일 입력으로 새 정상 뱅크를 구성함.
- 변경 변수는 **1차 보간 하나**. 기존 Top-3와 GPU KD-tree 후보 8개 + 기존 Float32 누적 순서의 거리 재계산 + 동점·경계 예외 시 전체 검사 비교. FPFH용 Morton+AABB·Radix, 두 FPS 가속, 집계, 평활화와 2차 보간은 공통.
- 시간은 ms/샘플. 1차 보간은 인덱스 준비와 예외 처리 포함. 전체 추론은 특징 추출+점수 계산으로 파일 읽기·쓰기·지표 계산 제외. 각 행의 단축률은 그 행의 기존판 대비임.

| 데이터/비교 | 실행 순서 | 1차 보간 기존→변경 (단축률) | 전체 평균 추론 기존→변경 (단축률) | 최종 점 점수 불일치 |
|---|---|---:|---:|---:|
| 캡슐 · 이전 세션 | 기존 → 변경 | 197.69 → 135.68 (31.37%) | 1,349.69 → 1,281.90 (5.02%) | 0 / 65,000,000 |
| 캡슐 · 반대 순서 | 변경 → 기존 | 213.03 → 139.08 (34.71%) | 1,444.51 → 1,351.62 (6.43%) | 0 / 65,000,000 |
| vase9 · 새 카테고리 | 기존 → 변경 | 51.58 → 39.86 (22.73%) | 368.52 → 358.38 (2.75%) | 0 / 4,564,539 |

두 새 비교에서 **69,564,539점 모두 동일**했고, 물체 점수 최대 절대 오차 0, 정상 메모리뱅크와 난이도별 지표도 일치했음. 캡슐에서 순서를 바꿔도 개선 방향이 같았으나, 실행 편차가 모두 제거됐다고 해석하지 않음. vase9의 결과는 한 카테고리 1쌍이며 전체 카테고리·다른 장치·다른 Float32 실행 환경에 대한 보장은 아님.
