**어떤 설정이 나았나?** C가 가장 빠르고 물체 AUROC가 가장 높았지만, 포인트 AP는 A보다 7.09%p 낮았음. D는 포인트 AUROC가 가장 높았지만, 포인트 AP는 A와 거의 같고 전체 추론은 A보다 18.2% 길었음. 이번 캡슐 한 카테고리에서는 **속도와 결함 위치 탐지를 함께 보면 A가 무난한 기준선**임.

## 비교 조건

- 모든 설정은 **전체 GPU KD-tree판(G)** 사용. 가림·무작위 제거 없는 캡슐 원본 50만 점 기준이며, 정상 54개·테스트 130개 목록이 같음.
- 특징 집계 중심점 4,096개, 평활화 중심점 1,024개·이웃 12개 유지. FPFH의 중간 스케일을 두 번 연결하는 원래 방식과 132차원 유지.
- 각 설정에 맞춰 메모리뱅크를 새로 구성함. 측정 시점은 서로 달랐으므로, 시간 차이 전체를 설정 변경만의 효과로 단정하지 않음.
- 추론 시간은 특징 추출+점수 계산임. 데이터 읽기·저장·지표 계산은 제외함. 성능은 전체 테스트(ALL) 기준이며, AUROC/AP 차이는 %p로 적음.

## 병목 단계와 자원

단위는 ms/샘플. 이전 단계별 보고서의 표시값을 사용함. 호출 합계와 동기화 계측이 섞여 있어 아래 행을 합산해 전체 추론으로 쓰지 않음.

|---|---:|---:|---:|---:|
| FPFH용 전체 점 이웃 조회 | 1106.81 | 1145.65 | 444.37 | 1583.64 |
| FPS 두 호출 합계 | 1027.45 | 1087.34 | 1215.23 | 1065.52 |
| 특징 집계 이웃 조회 | 31.90 | 7.04 | 7.85 | 6.95 |
| 점수 보간 두 호출 합계 | 278.04 | 296.49 | 331.85 | 289.81 |
| GPU KD-tree 구축 | 15.61 | 16.47 | 18.38 | 16.08 |

- **B−A:** 집계 이웃 조회는 31.90→7.04ms로 짧아졌지만, FPS 등 바꾸지 않은 단계의 시간도 실행마다 달라 전체 추론 개선은 확인되지 않았음.
- **C−B:** FPFH용 전체 점 이웃 조회는 1,145.65→444.37ms로 크게 줄었지만, 포인트 AUROC와 AP도 낮아졌음.
- **D−B:** FPFH용 전체 점 이웃 조회는 1,145.65→1,583.64ms로 늘었고, 포인트 AUROC와 AP는 B보다 높아졌음.
