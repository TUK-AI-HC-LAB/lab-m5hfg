# W48 Morton 공간 묶음과 STEP 군집 인덱스 비교

완료 샘플 6/6. 연산 시험이며 전체 추론·AUROC/AP 결과는 아님.

## 질문과 사전 가설

- 질문: 50회 Lloyd 군집화 대신 Morton 공간 정렬과 균등 묶음을 사용하면 정확한120-NN·FPFH를 유지하며 구성+조회 합계가 줄어드는가?
- H1: 반복 군집화 제거로 구성 비용 감소. H2: 공간 단절이나 큰 경계로 조회 후보가 늘어 전체는 느려질 수 있음.
- 양쪽 모두512개 묶음·같은 원본 Float32 좌표·Float64 거리/경계·같은 Radix120-NN 커널·거리/원본 인덱스 동점 순서를 유지함.
- 변경은 인덱스 구성뿐임. Morton 키를 만들 때만 좌표를10bit/축으로 양자화하며 원본 좌표·점·FPFH를 양자화하거나 제거하지 않음.
- 공간순 연속 점들을512개 균등 묶음으로 나누고 각 묶음의 bounding-box 중심과 전체 점을 포함하는 sphere 반경을 계산함. 완전한 LBVH나 논문 STEP 공식 구현 재현이 아님.
- 샘플마다 두 방법을 예열한 뒤4회 교차 순서로 구성과 조회를 각각 새로 실행함. 차이는 Morton−K-means. ms/샘플.
- 전체 확장 통과 기준: 6개 모두 이웃/FPFH 일치, 모든 샘플에서 구성+조회 중앙값 개선. 생성 시간만으로 채택하지 않음.

## 해석

- 이웃·FPFH 일치: True. 모든 샘플에서 구성+조회 개선: False.
- 다음 판단: 일괄 교체 조건을 통과하지 못해 전체 실행으로 확대하지 않음.
- 각 단계 중앙값과 합계 중앙값은 독립 집계하므로 소폭 합이 다를 수 있음.4회 반복은 같은 입력의 실행 변동 확인이며 독립 데이터 반복이 아님.
- 구조 변경 후에도 정확성을 유지할 수 있는지 확인하는 시험임. Morton 정렬 자체의 새로움을 주장하지 않음.

별도 계측 커널의 작업량이며 이 실행의 시간은 비교하지 않음. 같은 Radix 탐색에 인덱스만 바꿔 넣었고 이웃 결과도 일치함.

- Morton 균등 묶음의 경계가 느슨해져 후보 검사가 증가한다는 설명과 연결해 해석함. 반경은 해당 데이터 좌표 단위이므로 다른 데이터셋 사이의 반경 절대값을 직접 비교하지 않음.
- 서로 다른 물체와 점 수가 함께 달라진 표본이므로 성능 차이를 점 수 하나의 영향으로 단정하지 않음.

## 최종 판단

6개 표본 모두120-NN의 순서·집합 및FPFH40/80/120이 기준판과 일치함. 그러나 capsule의3개 표본은 모두 느려졌고 vase9의3개 표본은 모두 빨라짐. 사전에 정한6개 전체 통과 조건을 충족하지 못해 전체 추론·뱅크·AUROC 실행으로 확대하지 않음.

| 표본 집합 | 표본 수 | 기존 구성+조회 평균(ms) | Morton 구성+조회 평균(ms) | 차이(%) |
|---|---:|---:|---:|---:|
| capsule | 3 | 600.768 | 947.632 | +57.74 |
| vase9 | 3 | 156.350 | 94.822 | -39.35 |

각 표본의4회 합계 중앙값을 표본 간 동일 가중 평균한 값임. 차이(%) = (Morton 평균/기존 평균−1)×100. 전체 추론 시간 감소율이 아님.

- 생성은 약1~2ms로 줄었으나 capsule에서는 조회 비용 증가가 이를 상쇄하고도 남았음.
- capsule0의 평균 방문 묶음은2.267→14.583개, 후보 거리 계산은2,225.868→14,241.493회로 증가함. 큰 경계가 가지치기를 약화시키는 설명을 지지함. 시간 증가분의 모든 원인을 분리한 것은 아님.
- vase9에서도 후보 검사는 늘었지만 큰 초기 군집화 비용 제거 덕분에 합계는 감소함. ‘조회가 빨라진 것’과 ‘생성+조회가 빨라진 것’을 구분해야 함.
- 두 물체·데이터셋·점 수·밀도가 함께 다르므로 점 수만으로 실행 경로를 선택하는 규칙을 확정할 수 없음. 현재6개 결과에 맞춘 선택 규칙을 새로운 방법이라고 주장하지 않음.
- FPFH 특징을 바꾸지 않는다는 목표는 표본 수준에서 확인했지만, 현재의 단순 Morton 균등 묶음은 고해상도 capsule의 대체 인덱스로 미채택임.
- 추후 이 방향을 더 조사한다면 공간적으로 넓은 묶음을 줄이는 계층 분할과 실제LBVH를 별도 후보로 검토해야 함. 이번에는 그 추가 구현이나실험을 진행하지 않았음.
