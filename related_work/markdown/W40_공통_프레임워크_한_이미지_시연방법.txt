W40 공통 프레임워크 한 이미지 시연 방법

목적
  MVTec bottle의 실제 결함 이미지 한 장이
  원본 PNG -> 전처리 tensor -> AnomalyCLIP 출력 -> anomaly map -> 최종 score
  로 변환되는 과정을 화면과 코드로 보인다.

시연에서 사용할 고정 조건
  - framework: C:\Users\test\Downloads\dinomaly_share_codebase\dinomaly_share_codebase
  - method: anomalyclip
  - dataset/category: MVTec AD / bottle
  - query image: bottle/test/broken_large/000.png
  - checkpoint: ViSA-to-MVTec epoch_15.pth
  - GPU: cuda:0
  - 실행 시간: checkpoint load 포함 약 20~30초

시연 전 준비
  1. WSL과 GPU를 사용할 수 있는지 확인한다.
  2. 아래 두 파일을 미리 열어 둔다.
     - related_work/markdown/W40_공통_프레임워크_한_이미지_시연.md
     - method6/source/results/w40_common_framework_single_image/single_image_io_panel.png
  3. panel이 이미 있다면 바로 설명할 수 있다. 다시 실행하면 같은 조건의 artifact를 덮어쓴다.

진행 순서

1단계. 문제와 입력을 20초 안에 설명한다.

   모델에는 원본 PNG만 들어가고, 오른쪽의 ground-truth mask는 모델 입력이 아니라
   모델이 찾은 위치를 평가하기 위한 정답입니다."

  화면에서 보여 줄 것:
  - panel의 1번 원본 RGB 이미지

6단계. 모델 출력과 후처리를 코드로 설명한다.
  열 파일:
  C:\Users\test\Downloads\dinomaly_share_codebase\dinomaly_share_codebase\trainer\trainer_anomalyclip.py

  볼 함수:
  Trainer_AnomalyCLIP.predict()

  말할 순서:
  (1) _to_clip_normalized(): 공통 Dataset 입력을 CLIP 입력으로 변환
  (2) encode_image(): global feature와 patch feature 생성
  (3) _text_features(): normal/abnormal text feature 생성
  (4) global image feature x text feature: image-level score 계산
  (5) patch feature x text feature: 위치별 점수 계산
  (6) layer map 합산 -> bilinear resize -> Gaussian smoothing: final anomaly map 생성

  말할 내용:
  "global feature는 사진 전체 score를, patch feature는 위치별 map을 만듭니다.
   따라서 image score와 anomaly map은 같은 값이 아닙니다."

질문이 나오면 답할 내용
  Q. mask를 모델이 보고 결함을 찾았나?
  A. 아니다. score와 map은 image와 text prompt로만 계산한다. mask는 pixel AUROC와
     위치 비교를 위한 정답이다.

  Q. SimpleNet으로 바꾸면 모두 같은가?
  A. 설정, registry, Dataset/DataLoader, runner, metric 반환의 외부 흐름은 같다.
     그러나 SimpleNet은 discriminator logit, PatchCore는 normal memory와의 거리,
     AnomalyCLIP은 image/patch-text similarity로 score를 만들기 때문에 내부 수식은 다르다.

  Q. 0.991550보다 높으면 무조건 불량인가?
  A. 아니다. 현재 값은 fixed threshold가 아니다. 실제 판정 기준으로 쓰려면 정상/불량
     validation data 또는 운영 목표에 따라 calibration threshold를 별도로 정해야 한다.
