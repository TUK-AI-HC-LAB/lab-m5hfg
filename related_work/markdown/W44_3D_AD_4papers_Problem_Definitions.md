## 1. 공통 용어·기호 정의

아래 정의를 네 논문에 공통으로 사용함. 기호는 비교를 위한 통일 표기이며, 각 논문의 원래 기호와 다를 수 있음.

### 용어

| 용어                    | 쉬운 뜻                                         | 예시                                     |
| --------------------- | -------------------------------------------- | -------------------------------------- |
| 3D 점군                 | 물체의 표면을 나타내는 3차원 좌표들의 집합                     | 나사 표면을 스캔해 얻은 수많은 점                    |
| 고해상도 점군               | 표면의 작은 모양까지 표현하도록 많은 점으로 촘촘히 기록한 점군          | 작은 함몰도 점들의 위치 변화로 드러나는 스캔              |
| 3D 표현                 | 물체의 모양 정보를 모델이 활용할 수 있도록 나타낸 숫자 특징           | 표면의 굽음이나 주변 모양을 담은 특징                  |
| 곡률                    | 표면이 주변에서 얼마나 휘어지는지를 나타내는 기하 정보               | 평평한 면과 튀어나온 부분의 주변 모양 차이               |
| 자기지도 학습               | 사람이 붙인 정답 대신 데이터 자체에서 학습 과제를 만들어 특징을 학습하는 방식 | 점군의 정보를 가리고 원래 좌표를 복원하도록 학습            |
| 정상 데이터                | 결함이 없는 물체의 점군                                | 깨지거나 찌그러지지 않은 나사의 스캔                   |
| 검사 데이터                | 정상인지 결함인지 판단할 대상의 점군                         | 새로 생산된 나사의 스캔                          |
| 제품 종류(category)       | 정상·결함 구분이 아니라 물체 종류                          | 나사와 너트는 서로 다른 종류                       |
| 이상 점수                 | 정상에서 얼마나 벗어났는지를 나타내는 값. 높을수록 이상으로 판단함        | 나사 전체 점수는 불량 여부, 표면의 점별 점수는 결함 위치를 나타냄 |
| 가짜 결함(pseudo-anomaly) | 정상 데이터를 변형해 인위적으로 만든 결함                      | 정상 나사 점군의 일부를 눌러 가상 함몰을 만듦             |
| 통합 모델(unified model)  | 여러 제품 종류를 함께 학습하고 검사하는 하나의 모델                | 나사용·너트용 모델을 따로 만들지 않고 하나로 검사           |

### 기호

| 기호                    | 공통 의미                                                |
| --------------------- | ---------------------------------------------------- |
| $D_{\mathrm{normal}}$ | 정상 점군으로만 구성된 학습 데이터                                  |
| $D_{\mathrm{multi}}$  | 여러 제품 종류의 정상 점군을 합친 학습 데이터. 제품 종류 정보가 필요한 경우 별도로 명시함 |
| $X$                   | 검사할 물체 하나의 점군                                        |
| $s(X)$                | 물체 전체의 이상 점수                                         |
| $A(X)$                | 물체를 구성하는 점들의 이상 점수 모음                                |

**공통 조건:** 이상 탐지용 학습 데이터에 실제 결함 샘플이 주어지지 않는 설정을 다룸.
정상 데이터로 가짜 결함을 만들어 학습하는 것과 실제 결함 샘플을 제공받는 것은 다름.
검사 데이터의 정상·결함 정답과 결함 위치 정답은 평가용이며, 검사할 때 답으로 제공되는 입력이 아님.

**공통 성공 기준:** 정상 물체보다 결함 물체에 높은 이상 점수를 주고, 결함 위치의 점들에 높은 점수를 주는 것. 점수가 반드시 결함 확률을 의미하거나 논문 간 동일한 척도를 갖는 것은 아님.

**쉬운 전체 예시:** 정상 나사들의 스캔을 제공하고, 새 나사 하나를 검사함.
물체 전체 점수 $s(X)$로 이 나사가 이상한지 판단하고, 점별 점수 $A(X)$로 어느 부분이 이상한지 찾음.
여러 종류를 다루면 정상 나사와 정상 너트를 함께 제공하고 하나의 모델로 둘 다 검사함.

## 2. 논문별 Problem

아래의 ‘기존 접근’은 각 논문이 비교 대상으로 삼은 연구 흐름을 뜻함. 모든 기존 3D 이상 탐지 방법이 같은 한계를 가진다는 뜻은 아님. 쉬운 예시는 이해를 위한 설명이며 논문의 실험 사례를 그대로 옮긴 것이 아님.

### 문제 1. 고해상도 점군의 미세 결함 탐지 — Simple3D

**논문:** Towards High-Resolution 3D Anomaly Detection: A Scalable Dataset and Real-Time Framework for Subtle Industrial Defects

> 정상 제품의 점군 집합 $D_{\mathrm{normal}}$과 검사할 고해상도 점군 $X$가 주어졌을 때, 우리의 과제는 실제 결함 샘플 없이 정상 기준을 구성하고, 검사 물체의 이상 여부와 미세 결함의 위치를 나타내는 $s(X)$와 $A(X)$를 추정하는 것임.

목표: 고해상도 점군의 작은 결함을 놓치지 않으면서 실시간 검사에 적합한 속도를 확보하는 것. ‘실시간’은 성능 목표이며 출력 종류가 아님. MiniShift는 미세 결함을 평가하기 위해 함께 제안한 데이터셋임.

근거: 공식 PDF의 Introduction, Simple3D Method—Anomaly Detection, Experiment—Evaluation Metrics, Analysis on Runtime. 아래 원문 확인 표의 1번 PDF 참조.

#### 기존 3D 이상 탐지와 다른 점

- **기존 접근 한계:** 적은 점으로 검사하는 기존 방식은 작은 결함을 놓칠 수 있고, 고해상도로 검사하면 처리 비용이 커짐. 기존 벤치마크도 상대적으로 눈에 띄는 결함이 많아 미세 결함 검사 능력을 충분히 평가하기 어려웠음.
- **논문이 지목한 원인:** 점을 적게 뽑고 드문드문 계산한 점수를 전체 표면으로 퍼뜨리면 작은 결함의 정보와 위치 정밀도가 손실됨. 많은 영역을 처리하는 학습 기반 특징 추출기는 계산 부담도 커짐.
- **출발점이 된 관찰:** 논문 Figure 1에서 고해상도 점군에 보이던 작은 돌출이 점 수를 줄일수록 희미해지고, 매우 적은 점만 남기면 거의 사라지는 모습을 제시함. 이후 해상도 분석에서도 더 많은 점을 활용할수록 탐지 성능이 높아지는 경향을 보고함.
- **이 논문의 차별점:** 작고 미세한 결함을 평가하는 고해상도 데이터셋 MiniShift를 제안하고, 주변 모양을 직접 계산한 가벼운 3D 특징을 여러 크기 범위에서 모아 정확도와 속도를 함께 확보하려 함.
- **쉬운 예시:** 표면의 작은 함몰이 점을 적게 뽑는 과정에서 빠져버리면, 이후 모델이 좋아도 그 함몰을 찾기 어려움. 이 논문은 작은 결함 정보를 살리면서 빠르게 처리하는 데 초점을 둠.
- **설명할 핵심:** “정상과 결함을 구별한다는 목표는 같지만, 고해상도에서 미세 결함을 놓치지 않는 정확도와 처리 속도의 양립을 핵심 문제로 다룸.”

### 문제 2. 정상 데이터로부터의 3D 이상 판별·위치 추정 — CASL

**논문:** CASL: Curvature-Augmented Self-supervised Learning for 3D Anomaly Detection

> 제품 종류별 소수의 정상 점군으로 구성된 $D_{\mathrm{normal}}$과 검사할 점군 $X$가 주어졌을 때, 우리의 과제는 실제 결함 샘플을 학습에 사용하지 않고, 검사 물체의 정상·결함 여부를 판별하며 각 점의 이상 점수 $A(X)$를 추정하는 것임.

목표: 미세한 결함을 구별하면서, 물체 종류 분류나 부위 구분 같은 다른 3D 작업에도 활용 가능한 표현을 얻는 것. 최종적으로 물체 수준 점수 $s(X)$와 점별 점수 $A(X)$를 계산함.

근거: 공식 PDF의 Methodology—Problem Definition for 3D Anomaly Detection, Fine-tuning via Pseudo-Anomaly Classification, Anomaly Score for Inference, Experiments—Pre-training. 아래 표의 2번 PDF 참조.

#### 기존 3D 이상 탐지와 다른 점

- **기존 접근 한계:** 이상 탐지 전용 모델은 정상·결함 판별에 특화되어 다른 3D 작업으로의 활용이 제한적이었음. 반대로 다양한 작업에 활용하려는 범용 자기지도 학습 모델은 단순히 fine-tuning하는 것만으로는 이상 탐지 성능이 충분하지 않았음.
- **논문이 지목한 원인:** 기존 자기지도 학습은 좌표에서 좌표를 복원하면서, 미세한 모양 차이를 배우기보다 주어진 위치 정보에 의존하는 ‘기하학적 지름길’을 택할 수 있음. 논문은 이로 인해 미세한 차이를 구별하는 표현이 충분히 학습되지 않는 문제를 지적함.
- **출발점이 된 관찰:** 학습 없이 각 점의 곡률만 이상 점수로 사용해도 일부 기존 자기지도 학습 모델과 이상 탐지 전용 모델보다 높은 성능을 얻었음. 이는 표면이 어떻게 휘어 있는지가 3D 구조적 결함을 찾는 강력한 단서임을 보여 줌.
- **이 논문의 차별점:** 이 관찰을 곡률 기반 판별에서 끝내지 않고, 곡률을 좋은 특징을 학습하는 단서로 확장함. 사전학습에서는 좌표 입력을 모두 가리고 여러 크기 범위의 곡률 정보로 원래 좌표를 복원하게 함. 이후 정상 데이터에서 만든 가짜 결함을 구별하도록 미세조정하여 실제 이상 탐지에 적용함.
- **쉬운 예시:** 나사 표면의 위치를 그대로 따라 그리는 것과 작은 돌출을 구별하는 것은 다른 능력임. CASL은 표면의 휘어진 정도를 단서로 모양을 복원하게 하여, 결함의 미세한 모양 차이도 담는 특징을 학습하려는 것임.
- **설명할 핵심:** “곡률만으로도 결함을 잘 찾는다는 관찰에서 출발해, 곡률을 이용한 학습으로 이상 탐지 성능과 다른 3D 작업에 대한 활용성을 함께 확보하려는 방법임.”

여기서 ‘소수’는 점군 하나의 점 수가 아니라 정상 물체 스캔의 수를 뜻함. 종류별 정상 스캔이 적은 데이터셋 조건을 따른 것이며, 정상 데이터가 반드시 적어야 하는 방법이라는 뜻은 아님.

### 문제 3. 실제 결함 샘플 없이 수행하는 3D 이상 탐지 — PA3AD

**논문:** Physics-inspired Pseudo Anomaly Generation and Prototype Feature Guidance for 3D Anomaly Detection

> 정상 점군만으로 구성된 학습 데이터 $D_{\mathrm{normal}}$과 검사할 점군 $X$가 주어졌을 때, 우리의 과제는 실제 결함 샘플 없이 이상 점수 함수를 학습하여, 검사 물체 전체의 이상 점수 $s(X)$와 각 점의 이상 점수 $A(X)$를 추정하는 것임.

목표: 실제 결함을 모으기 어려운 상황에서도 정상·결함의 차이를 잘 구별하고 결함 위치를 찾는 것. 물리적 특성을 고려한 가짜 결함과 정상 대표 특징은 주어진 데이터가 아니라 학습 과정에서 만드는 해결 수단임.

근거: 공개 원문 PDF의 §3.1 Problem definition, §3.2 Pipeline overview, §3.5 Momentum-based normal feature generation, §3.7 Difference-aware fusion block and loss function. 아래 표의 3번 PDF 참조.

#### 기존 3D 이상 탐지와 다른 점

- **기존 접근 한계:** 실제 결함이 없는 학습 조건에서 정상과 결함의 차이를 익히기 어려움. 가짜 결함을 활용하는 기존 방법도 있었지만, 단순한 변형만으로 실제 산업 결함을 충분히 반영하기 어려웠음.
- **논문이 지목한 원인:** 무작위·단순 변형이 실제 결함의 연속적인 표면 변화와 다르면 학습 신호에 편향이 생길 수 있음. 또한 정상과 결함의 특징 차이를 충분히 구별하지 못하면 비슷한 국소 모양을 혼동할 수 있음.
- **출발점이 된 관찰:** 제품 표면이 손상되어 살짝 눌려 들어간 부분과, 제작할 때 의도적으로 눌러 만든 정상 무늬는 작은 영역만 보면 모양이 비슷할 수 있음. 둘 다 주변 표면보다 안쪽으로 들어가 있으므로, 표면이 얼마나 휘었는지 또는 어느 방향을 향하는지만으로는 결함인지 원래 있어야 하는 무늬인지 구별하기 어려울 수 있다는 뜻임. 논문은 이 예시로 정상과 결함의 특징이 비슷해질 수 있음을 설명함.
- **이 논문의 차별점:** 실제 결함의 형성 특성을 참고해 더 그럴듯한 가짜 결함을 만들고, 학습 중 누적한 정상 대표 특징을 함께 활용하여 정상과 결함의 차이를 구별하려 함.
- **쉬운 예시:** 점 몇 개를 아무 방향으로 흩뜨리는 것보다 표면이 주변과 이어지면서 눌리거나 휘는 형태를 만들어 학습하고, 그 결과를 정상의 대표 특징과 비교하도록 하는 것임.
- **설명할 핵심:** “실제 결함 없이 탐지한다는 설정은 유지하면서, 가짜 결함의 현실성과 정상 기준을 활용한 차이 학습을 개선함.”

### 문제 4. 제품 종류의 혼동을 줄이는 다종 3D 이상 탐지 — SeDiR

**논문:** A Semantically Disentangled Unified Model for Multi-category 3D Anomaly Detection

> 여러 제품 종류의 정상 점군을 합친 $D_{\mathrm{multi}}$와 학습용 제품 종류 정보, 그리고 검사할 점군 $X$가 주어졌을 때, 우리의 과제는 실제 결함 샘플 없이 하나의 통합 모델을 학습하여, 검사 물체 전체의 이상 점수 $s(X)$와 각 점의 이상 점수 $A(X)$를 추정하는 것임.

목표: 여러 제품 종류를 하나의 모델로 검사하면서, 종류 간 특징 혼동으로 생기는 오탐과 위치 추정 오류를 줄이는 것. 학습용 제품 종류 정보는 정상·결함 정답과 다르며, 검사 물체의 결함 정답을 제공한다는 뜻이 아님.

근거: 공식 PDF의 §3 Problem statement, §3.1 Auxiliary category classification loss, §3.2 Category-Conditioned Contrastive Learning, §3.4 Anomaly Scoring. 아래 표의 4번 PDF 참조.

#### 기존 3D 이상 탐지와 다른 점

- **기존 접근 한계:** 제품 종류마다 모델을 따로 만들면 관리 부담이 커짐. 이미 제안된 통합 모델도 여러 종류를 하나로 처리하는 과정에서 정상 물체에 높은 이상 점수를 주거나 결함 위치를 잘못 추정할 수 있었음.
- **논문이 지목한 원인:** 서로 다른 제품 종류의 특징이 섞이면, 입력이 어떤 물체인지 명확히 구분하지 못한 채 잘못된 종류의 정상 모양을 기준으로 복원할 수 있음. 논문은 이를 종류 간 특징 얽힘 문제로 설명함.
- **출발점이 된 관찰:** 기존 통합 모델의 특징을 시각화했을 때 서로 다른 종류의 특징 분포가 겹쳤고, 정상 검사 데이터에서도 제품 종류 분류 점수가 낮은 샘플은 복원 오차가 큰 경향을 보였음. 논문 Figure 2에서 이 관계를 제시함.
- **이 논문의 차별점:** 통합 모델이 물체의 종류를 구분하는 특징을 먼저 형성하고, 그 정보와 입력의 기하 구조를 이용해 복원하도록 함. 서로 다른 제품 종류의 특징 혼동을 명시적인 해결 대상으로 삼음.
- **쉬운 예시:** 정상 나사를 너트의 모양을 기준으로 복원하면, 결함이 없어도 원본과 차이가 커질 수 있음. 나사는 나사로 이해한 뒤 복원하도록 하여 이런 오탐을 줄이려는 것임.
- **설명할 핵심:** “여러 제품을 하나의 모델로 검사하되, 제품 종류를 혼동해서 정상도 이상으로 판단하는 문제를 줄이는 데 초점을 둠.”

## 3. 읽을 때 구분할 점

- 확인 완료한 네 편의 공통 탐지 과제는 **물체의 이상 여부와 결함 위치 추정**임. 서로 다른 방법을 쓴다고 반드시 입력·출력이 다른 문제를 푸는 것은 아님.
- 1번의 고해상도·속도, 2번의 표현 학습, 3번의 가짜 결함 활용, 4번의 종류 간 혼동 해소는 각 논문의 목표 또는 해결 초점임. 이를 모두 별개의 입력 조건으로 바꾸지 않음.
- CASL에서 말하는 학습 절차의 ‘통일’과 SeDiR의 ‘여러 종류를 한 모델로 처리’는 같은 뜻이 아님. CASL을 다종 통합 모델로 단정하지 않음.
