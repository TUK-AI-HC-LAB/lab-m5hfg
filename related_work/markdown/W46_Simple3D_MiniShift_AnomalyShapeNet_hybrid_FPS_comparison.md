# W46 Simple3D — MiniShift·Anomaly-ShapeNet GPU KD-tree vs FlashFPS

**두 데이터셋의 52개 카테고리 모두 평균 추론이 빨라졌음.** 특징 집계만 FlashFPS로 바꿨을 때 전체 추론은 MiniShift에서 **24.3%**, Anomaly-ShapeNet에서 **21.8%** 단축됨. 두 데이터셋 모두 포인트 AUROC는 올랐지만, 물체 AUROC는 낮아졌음.

## 비교 조건

- **기존:** GPU KD-tree + 원래 PointNet2 CUDA FPS. **혼합:** 같은 GPU KD-tree에서 특징 집계에만 FlashFPS의 FPS-Prune 변형 적용. 평활화 FPS는 두 버전 모두 기존 방식 유지.
- 혼합 버전의 특징 집계: 무작위 후보 25%(시드 42)에서 2,048개를 FPS로 선택하고, 미선택 후보를 인덱스 순서대로 2,048개 채워 총 4,096개 사용. 두 버전 모두 평활화 중심점 1,024개, FPFH 40·80·120, 집계·평활화 이웃 수 128·12개 유지.
- RTX 5080에서 카테고리별 두 버전을 재측정하고, 각 버전의 정상 메모리뱅크를 새로 구성함. MiniShift는 정상 1,017개·테스트 1,560개, Anomaly-ShapeNet은 정상 160개·테스트 1,312개를 버전별로 사용함. **총 104회 검증 완료.**
- 데이터셋별 평균은 카테고리 동일 가중치. 각 칸은 **기존 → 혼합 (혼합−기존)**으로 표시함. 지표 차이는 %p. 추론은 특징 추출과 점수 계산의 합으로, 입출력·지표 계산은 제외함.

## 해석

- **시간 단축은 주로 특징 집계 FPS에서 나옴.** MiniShift는 859.43 → 111.57ms, Anomaly-ShapeNet은 103.40 → 16.20ms. 평활화 FPS는 그대로이며, FPFH용 120-NN 조회가 두 데이터셋의 혼합 버전에서 가장 오래 걸리는 단계로 남음.
- **속도와 탐지 성능을 함께 봐야 함.** 물체 AUROC 하락은 MiniShift(−1.88%p)가 Anomaly-ShapeNet(−0.20%p)보다 컸음. 포인트 AUROC는 각각 +1.14%p, +0.46%p였지만, 포인트 AP는 MiniShift에서 −0.07%p, Anomaly-ShapeNet에서 +0.55%p로 방향이 달랐음.
- 단일 시드·카테고리별 버전당 1회 측정임. 두 데이터셋의 절대 AUROC는 실험 대상과 점군 조건이 달라 직접 비교하지 않고, 각 데이터셋 안에서 변경 전후의 차이를 해석함.
