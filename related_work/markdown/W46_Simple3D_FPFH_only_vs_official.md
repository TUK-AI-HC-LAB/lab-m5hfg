# W46 Simple3D: FPFH-only vs 공식 호환판

- **F**: FPFH 계산과 내부 이웃 탐색만 GPU KD-tree/CUDA로 변경. 128개·12개 이웃 탐색은 공식 GPU `KNN_CUDA` 유지.
- **O**: 공식 호환판. FPFH는 CPU Open3D, 중심점·평활화 이웃은 GPU KNN_CUDA.
- 검증 완료된 Anomaly-ShapeNet 40개·MiniShift 12개, 동일한 입력 목록과 해상도 기준. 두 실행 시점은 다름.
- **F-O = F 측정값 − O 측정값.** 추론 시간의 음수는 F가 빠름을, 정확도의 양수는 F가 높음을 뜻함. 반올림 전 값으로 차이 계산.
- 추론은 특징 추출+점수 계산. 입력 읽기·저장·지표 계산 제외. p95는 카테고리별 테스트 샘플 추론 시간의 95백분위.

## 해석과 원본 기록
