**[재구성 기반 산업 이상탐지, 연속 촬영, 실시간 생산라인 적용] 정상적인 액체 움직임과 결함을 구분하면서 제한된 시간 안에 검사해야 함 → 잡음 제거 방식의 재구성 학습, 프레임 선택·영역 분할, 제품 단위 판정으로 대응.**

- 조사 목적: 기존 이미지 이상탐지를 더 역동적이고 제약이 많은 산업 환경에 적용한 사례를 확인한다.
- 핵심 판단: 이 논문은 **이미지 검사 모델을 생산라인의 촬영·처리·판정 과정으로 확장한 적용 사례**다.
- 발표 범위: 시간 순서 자체를 학습하는 동영상 모델이나 지속적으로 모델을 갱신하는 온라인 학습 연구로 분류하지 않는다.
- 벤치마크 관점: 기업의 산업 테스트 데이터를 사용하므로, 공개 데이터로 바로 재현할 후보인지 여부는 추가 확인이 필요하다.

## 동작 과정 한눈에 보기

**그림 설명:** 논문을 바탕으로 재구성한 설명용 도식이다. 실제 장비 사진이나 모델 출력이 아니며, 복원 과정의 빨간 점은 결함을 설명하기 위한 예시다. 영역 분할 그림은 선택된 프레임 한 장의 5개 용기 × 4개 영역을 나타낸다. 이를 3개 프레임에 적용하면 총 60개 패치가 된다.

설명할 때는 **“촬영 → 3장 선택 → 60개 패치 → 복원 → 차이 계산 → 제품 판정”** 순서로 그림을 짚으면 된다. 500ms는 촬영 사이의 처리 제약이며, 측정된 모델 추론 시간 자체를 뜻하지 않는다.

## 1. 한 문장으로 이해하기

**정상 제품의 모습을 배운 AI가 생산라인에서 촬영한 제품을 검사하고, 다음 촬영 전에 불량 여부와 의심 위치를 알려주는 연구다.**

핵심은 이미지 이상탐지 모델을 실제 장비의 촬영·계산·판정 과정에 맞게 구성하는 것이다. 시간에 따른 움직임이나 사건 순서를 학습하는 동영상 모델과는 구분한다.

## 2. 무엇을 검사하고, 무엇이 어려운가?

검사 대상은 액체가 든 작은 용기 5개가 붙어 있는 BFS 제품이다. BFS는 용기 성형·충전·밀봉을 수행하는 제조 공정을 뜻한다.

제품을 움직이며 촬영하면 액체가 흔들리고 기포나 물방울이 생긴다. 이러한 정상적인 변화도 결함처럼 보일 수 있다. 따라서 단순히 다른 부분을 찾는 것만으로는 부족하다. 정상 변동을 허용하면서 불량을 찾아야 하고, 생산 속도에도 맞춰야 한다.


## 3. 불량을 찾는 원리: 입력과 복원 결과 비교

**재구성**은 입력 이미지를 압축한 뒤 다시 그리는 것이다. 정상적인 제품 모습에 익숙해진 모델이 결함 부분을 정상적인 모습으로 복원하면, 원본과 복원본 사이에 차이가 생긴다. 이 차이를 이상 신호로 활용한다. 모든 결함이 반드시 제거되어 복원된다는 보장은 없다.

```text
제품 촬영
   ↓
검사할 영역을 작은 이미지로 분할
   ↓
모델이 이미지 복원
   ↓
원본과 복원본 비교
   ↓
이상 점수가 기준을 넘으면 불량 판정
   ↓
차이가 큰 위치를 히트맵으로 표시
```

이상 점수는 `1 − SSIM(원본, 복원본)`이다. SSIM은 두 이미지의 구조가 얼마나 비슷한지를 측정하는 지표다. 이 설정에서는 구조가 덜 비슷할수록 이상 점수가 커진다. 히트맵은 원본과 복원본의 픽셀 차이로 만든다.

근거: 원문 §5.2.2, 식 (10)–(12).

## 4. 결함까지 그대로 따라 그리는 문제는 어떻게 줄이나?

일반적인 재구성 모델은 입력을 너무 잘 복사해서 결함까지 복원할 수 있다. 그러면 원본과 복원본의 차이가 작아져 불량을 놓친다.

이 논문은 정상 이미지에 불규칙한 Perlin 잡음을 넣고 정상 구조를 복원하도록 학습한다. 쉽게 말해, 정상 사진을 일부러 훼손한 뒤 원래 모습을 되찾는 연습을 시키는 것이다.

모델은 ResNet 계열의 인코더와 디코더를 사용하는 재구성 구조이며, GAN 방식으로 학습한다. 인코더는 이미지를 특징으로 압축하고, 디코더는 그 특징으로 이미지를 복원한다. GAN의 판별기는 학습 중 복원 품질을 개선하는 데 관여한다.

학습 원본은 정상 제품이지만 인공적인 손상을 추가한다. 또한 **최종 판정 기준값은 별도의 정상·불량 보정 데이터로 정한다.** 따라서 실제 불량 정보가 전체 절차에서 전혀 사용되지 않는다고 설명하면 부정확하다.

## 5. 어떻게 실시간 검사에 맞추나?

모든 이미지를 전부 처리하는 대신, 검사할 프레임과 영역을 선택해 계산량을 줄인다.

| 단계 | 구성 | 목적 |
|---|---|---|
| 프레임 선택 | 촬영 시퀀스의 처음·8번째·마지막, 총 3장 | 처리할 이미지 수 감소 |
| 용기 분리 | 한 제품의 용기 5개 | 용기별 검사 |
| 영역 분리 | 용기마다 4개 영역 | 영역별 작은 이미지로 검사 |
| 묶음 처리 | 3장 × 5개 × 4개 = 60개 패치 | 한 촬영 묶음의 검사 단위 구성 |
| 결과 통합 | 하나라도 불량 기준을 넘으면 제품 불량 판정 | 부분 결함이 전체 평균에 묻히는 문제 방지 |

패치는 큰 이미지에서 잘라낸 작은 이미지다. 모델의 입력 패치 크기는 256 × 256이며 흑백 영상이다.

논문은 **연속 촬영 사이의 500ms 안에 처리하는 제약**을 설정하고 이를 만족하는 구성을 검증한다. 여기서 500ms는 요구되는 처리 시간이며, 그 자체가 측정된 추론 지연이나 일반 동영상 FPS를 뜻하지 않는다.

## 7. 보고된 결과와 해석

논문은 패치·용기·제품·반복 검사 등 평가 단위를 나눠 보고한다. 예를 들어 Table 2의 제품 묶음 단위 정확도는 95.93%다. 이는 해당 기업 테스트 조건의 결과이며, AUROC나 공개 벤치마크 성능과 같은 값이 아니다.

최종 검증에는 같은 제품을 10회 검사하고 7회 이상 맞추면 정분류로 인정하는 별도 규칙도 사용한다. 따라서 반복 검증 결과를 단일 촬영의 정확도로 설명하지 않아야 한다.

| 확인 항목 | 논문에서 확인되는 내용 | 발표에서의 해석 |
|---|---|---|
| 제품 묶음 정확도 | Table 2: 95.93% | 해당 기업 테스트 조건의 Accuracy이며 AUROC가 아님 |
| 최종 반복 검증 | 제품당 10회 검사, 7회 이상 정답이면 정분류 인정 | 단일 촬영 성능과 구분해서 설명 |
| 실시간 조건 | 연속 촬영 사이 500ms 처리 제약 | 요구 시간이며, 이 값만으로 동영상 FPS를 계산하지 않음 |
| 재현성 | 공식 코드·공개 데이터 경로 unverified | 공개 벤치마크에서 직접 비교 가능한지는 미확인 |

표의 값은 원문 보고값이다. 평가 단위가 서로 달라 하나의 성능 수치로 합치지 않는다.

## 8. QueCo 확장 방향 조사와의 연결

**조사로 확인한 점:** 이미지 이상탐지의 산업 적용에는 탐지 정확도뿐 아니라 프레임 선택, 영역 분할, 제품 단위 결과 통합, 처리 시간 제약이 함께 필요하다.

**본 논문의 위치:** 재구성 기반 이미지 검사를 연속 촬영이 있는 생산라인에 통합한 사례다.
