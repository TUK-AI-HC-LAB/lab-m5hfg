# W46 Simple3D FPFH만 GPU KD-tree로 변경한 결과 비교

## 변경 범위

- F: FPFH 및 그 내부 이웃 탐색만 GPU KD-tree/CUDA FPFH로 변경한 새 실행.
- O: 기존 W46 공식 호환판. G: 기존 W46의 FPFH·중심점 이웃 탐색을 모두 GPU KD-tree로 바꾼 실행. O/G 재실행하지 않고 기존 결과를 참조함.
- **F의 중심점 128개 이웃은 native KNN_CUDA, 원래 4000+96 조회 배치 유지. 점수 평활화 12개 이웃도 native KNN_CUDA 유지.**
- 공식 get_fpfh_features의 FPFH 구간만 대체함. 앞뒤 코드는 원본 AST 그대로 유지하고 해시를 기록함. 기존 두 torch.cat 연결, 좌표 이동·Float32 변환, FPS·gather·LFSA, coreset 5%, torch.cdist/min, full-sort 보간, top80 평균, CPU 점수맵·인덱스는 변경하지 않음.
- FPFH 구간에는 CPU 법선 계산 유지, Float32 GPU 좌표/법선 전송, GPU KD-tree k120 조회와 40/80/120 재사용, 기존 검증 CUDA SPFH/FPFH 커널이 포함됨. CPU FPFH와 bitwise 동일성을 주장하지 않음.
- 같은 52개 범주·원본 해상도·공식 DataLoader·설정·native 환경. 기존 입력 manifest와 공식 코드 해시를 확인함. 새 뱅크·새 점수를 생성하며 기존 뱅크·점수를 재사용하지 않음.
- 두 기존 모드의 측정과 날짜·시점이 다르므로 열·타 작업·스케줄링 차이를 완전히 통제한 동시 반복 비교는 아님. 단일 실행 측정이며 유의성 검정은 하지 않음.
- 시간·메모리·사용률 계측은 기존 W46 worker/controller와 같은 방식을 유지함. 약 0.5초+조회 지연으로 GPU 사용률·전체 VRAM·전력·온도·CPU RSS 기록함.
- 최대 Torch 할당은 CuPy 외부 할당을 제외함. GPU 전체 VRAM은 화면·다른 앱을 포함한 표본 최대임. 중첩 단계·서로 다른 시계는 단순 합산할 수 없음.
- 아래 O/G/F 평균은 **현재 F 완료 범주와 동일한 범주만** 평균함. 52개 완료 전 데이터셋 전체 평균이 아님. 추론=특징+점수이며 입력/저장/지표 계산 제외함.
