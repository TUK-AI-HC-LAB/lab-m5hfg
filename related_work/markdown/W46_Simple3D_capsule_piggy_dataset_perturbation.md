# W46 Simple3D — 캡슐·piggy 데이터 변형 실험

## 1. 무엇을 확인했는가

같은 개수의 점을 제거해도 **한쪽 표면을 통째로 가리는 것**과 **전체 표면을 듬성듬성하게 만드는 것**의 영향이 다른지 확인함. MiniShift의 `capsule`과 `piggy`를 대상으로, 기존 GPU KD-tree판(G)을 사용함.

- 모델 및 학습 조건은 카테고리 내에서 고정함. 원본 정상 데이터(캡슐 54개, piggy 100개)로 메모리뱅크를 각각 한 번 구성함.
- **테스트 점군만 변경**함. 각 카테고리의 동일한 테스트 130개에 5조건을 적용해 총 **1,300회 추론**함. 원본 데이터 파일을 수정하지 않음.
- G는 FPFH 내부 이웃 탐색뿐 아니라 중심점 128개·점수 평활화 12개 이웃에도 GPU KD-tree를 쓰는 버전임. FPFH-only판이 아님.

## 2. 데이터를 어떻게 바꿨는가

| 조건 | 제거 방법 | 남은 점 수 |
|---|---|---:|
| 원본 | 점을 제거하지 않음 | 500,000 |
| 50% 가림 | X 좌표가 작은 쪽의 연속 영역만 남김 | 250,000 |
| 무작위 50% 제거 | 전체 점군에서 무작위로 절반을 남김 | 250,000 |
| 75% 가림 | X 좌표가 작은 쪽의 연속 영역을 더 좁게 남김 | 125,000 |
| 무작위 75% 제거 | 전체 점군에서 무작위로 4분의 1을 남김 | 125,000 |

가림은 **점 개수 기준**이며 표면 면적의 50%·75%를 뜻하지 않음. 정답을 보고 가릴 위치를 고르지 않았음. 공식 입력 전처리 뒤에 변형을 적용해 좌표계를 유지하고, 남은 점에 원래 정답을 대응시킴. 실제 카메라나 센서의 가림을 그대로 재현한 것은 아님.

## 4. 같은 점 수일 때 가림의 영향

아래는 **가림−무작위 제거**의 차이임. 점의 개수는 같지만 남는 위치와 결함 점 비중은 다름.

| 카테고리 | 제거 비율 | 물체 AUROC 차이 (%p) | 포인트 AUROC 차이 (%p) | 포인트 AP 차이 (%p) | 평균 추론 차이 (ms) |
|---|---:|---:|---:|---:|---:|
| capsule | 50% | -23.50 | -10.42 | -9.99 | 8.40 |
| capsule | 75% | -27.58 | -20.46 | -16.58 | 7.97 |
| piggy | 50% | 4.33 | -7.38 | 1.06 | 10.23 |
| piggy | 75% | -1.08 | -9.99 | 2.30 | 26.32 |

- **캡슐:** 가림에서 물체 AUROC가 무작위 제거보다 50% 조건에서 23.50%p, 75% 조건에서 27.58%p 낮았음.
- **piggy:** 50% 가림에서는 물체 AUROC가 무작위 제거보다 4.33%p 높았지만, 포인트 AUROC는 7.38%p 낮았음. 75% 가림에서는 두 AUROC가 모두 낮았음. 따라서 가림이 모든 지표를 항상 떨어뜨린다고 볼 수 없음.
- **공통:** 두 카테고리의 50%·75% 가림 모두 같은 점 수의 무작위 제거보다 포인트 AUROC가 낮았음. 추론 시간 차이는 8~26ms 수준으로, 탐지 지표 차이와 달리 같은 점 수에서 큰 시간 차이는 없었음.

## 5. 왜 성능이 달라졌는가

**직접 확인된 차이는 결함이 아예 보이지 않는 사례가 늘었다는 것임.** 무작위 제거에서는 두 카테고리 모두 결함이 통째로 사라진 사례가 없었음. 가림에서는 캡슐이 62개→89개, piggy가 42개→76개로 증가함. 이는 물체 AUROC 하락을 설명할 근거 중 하나임. 다만 미관측 개수만으로 AUROC 변화량 전체를 설명할 수는 없음.

남아 있는 점의 탐지 품질을 따로 보기 위해, 원본 점수도 **변형에서 살아남은 바로 그 점들**만 골라 AP를 다시 계산함.

| 카테고리 | 조건 | 같은 점의 원본 AP (%) | 변형 AP (%) | 변형−원본 (%p) |
|---|---|---:|---:|---:|
| capsule | 50% 가림 | 17.60 | 20.01 | 2.41 |
| capsule | 무작위 50% 제거 | 22.87 | 30.00 | 7.13 |
| capsule | 75% 가림 | 14.52 | 19.52 | 5.00 |
| capsule | 무작위 75% 제거 | 22.82 | 36.10 | 13.27 |
| piggy | 50% 가림 | 2.75 | 2.48 | -0.26 |
| piggy | 무작위 50% 제거 | 2.94 | 1.42 | -1.52 |
| piggy | 75% 가림 | 2.29 | 3.33 | 1.05 |
| piggy | 무작위 75% 제거 | 2.94 | 1.04 | -1.91 |

- 캡슐은 50%·75% 가림에서 **같은 점 기준 AP가 각각 2.41%p·5.00%p 상승**함. 전체 물체 판별 성능이 떨어졌다고 해서, 남아 있는 결함까지 모두 더 못 찾았다는 뜻은 아님.
- piggy의 75% 가림은 물체·포인트 AUROC가 원본보다 낮지만, 같은 점 기준 AP는 1.05%p 높았음. AUROC와 AP의 판단이 다를 수 있고, 원본 전체 AP와 변형 AP의 직접 비교에는 결함 비중 차이도 섞임.
- **이웃 거리:** 두 카테고리 모두 무작위 50% 제거는 120번째 이웃 거리 중앙값 비율이 약 1.41배, 75% 제거는 약 1.99배였음. 가림은 전체 표본을 집계한 중앙값 비율이 약 1.00배였음. 무작위 제거는 남은 표면을 전반적으로 듬성듬성하게 만들었고, 가림은 일부 표면 자체를 없앤다는 차이가 관측됨. 중앙값 1.00배가 절단 경계의 변화가 없다는 뜻은 아님.
- **경계 오탐 가설:** 75% 가림의 경계 가까운 정상 점수 변화 중앙값은 캡슐 +0.04, piggy +0.44였음. 점수 변화는 관측됐지만, 판정 임계값을 넘은 오탐 개수까지 측정한 것은 아니므로 경계 오탐이 주원인이라고 단정하지 않음.

## 7. 결론과 실험 범위

같은 개수의 점을 남겨도 **점이 빠진 위치에 따라** 탐지 결과가 달랐음. 가림은 결함을 관측하지 못하는 사례를 늘렸고, 두 카테고리에서 포인트 AUROC가 무작위 제거보다 낮았음. 반면 남은 점만 비교한 AP는 항상 하락하지 않았음. **두 카테고리·한 절단 방향·한 무작위 설정에서 확인한 결과**이며, 모든 제품이나 실제 센서 가림으로 일반화하지 않음.
