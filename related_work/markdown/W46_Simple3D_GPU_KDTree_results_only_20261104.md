# W46 Simple3D GPU KD-tree — 전체 측정 결과

- 범위: Anomaly-ShapeNet 40개, MiniShift 12개. 정상 학습 1,177개, 테스트 2,872개. 전체 실행 약 2시간 43분.
- 구현: CuPy GPU KD-tree + 별도 CUDA FPFH 수정판. 공식 무수정 구현체 결과가 아님.
- AUROC/AP는 높을수록 좋음. 시간은 낮을수록 빠름. 메모리뱅크 구성은 초, 추론은 ms/샘플, 메모리는 GB(10⁹ bytes) 단위임.
- 평균 추론 = 특징 추출 + 점수 처리. 입력 읽기·파일 저장·평가 지표 계산 제외함.

## 5. 측정 범위와 원시 결과

- 최대 Torch GPU 할당은 PyTorch가 기록한 값임. CuPy KD-tree 등 외부 할당을 포함한 전체 VRAM 사용량이 아님.
- 이 이전 실행에서는 카테고리별 GPU 사용률·전력·온도 시계열을 기록하지 않았음. 없는 값은 표에 만들지 않음.
- 범주 전체 처리 시간에는 해당 worker의 준비·워밍업·학습·테스트·저장·지표 계산 등이 포함되며 순수 추론 시간과 다름.
