## 초록

본 논문은 이상을 탐지하고 위치를 찾기 위한 단순하고 실제 적용하기 쉬운 네트워크인 **SimpleNet**을 제안함. SimpleNet은 네 부분으로 구성됨.

1. 사전학습된 **특징 추출기**: 이미지의 지역 특징을 만듦.
2. 얕은 **특징 어댑터**: 지역 특징을 현재 검사 대상 도메인에 맞춤.
3. **이상 특징 생성기**: 정상 특징에 가우시안 잡음을 더해 가짜 이상 특징을 만듦.
4. 이진 **이상 판별기**: 정상 특징과 이상 특징을 구분함.

추론할 때는 이상 특징 생성기를 제거함. 저자들의 핵심 생각은 세 가지임. 첫째, 사전학습 특징을 대상 도메인에 맞는 특징으로 바꾸면 도메인 편향을 줄일 수 있음. 둘째, 결함은 이미지 공간에서 공통점이 적으므로 이미지가 아니라 특징 공간에서 가짜 이상을 만드는 편이 효과적임. 셋째, 단순한 판별기는 효율적이고 실제 적용에 적합함. SimpleNet은 MVTec AD에서 이미지 수준 이상 탐지 AUROC 99.6%를 달성했으며, 다음으로 좋은 모델보다 오류를 55.5% 줄였다고 보고함. 3080 Ti GPU에서 초당 77장을 처리했다고 보고함.

## 1. 서론

이미지 이상 탐지와 위치 찾기의 목표는 이상 이미지를 구분하고 이상 부분의 위치를 찾는 것임. 산업 검사에서는 얇은 흠집처럼 미세한 결함부터 부품 누락처럼 큰 구조 결함까지 형태가 다양하고, 실제 불량 예시는 적어서 어려움. 그래서 학습에는 정상 샘플만 사용하는 비지도 방식이 주로 사용됨.

기존 접근은 크게 세 부류임.

- **복원 기반 방법**: 정상 데이터만으로 학습한 네트워크는 이상 부분을 정확히 복원하지 못한다고 가정함. 입력과 복원 이미지의 픽셀 차이를 이상 점수로 사용함. 하지만 모델이 너무 잘 일반화하면 이상도 복원해 놓칠 수 있음.
- **합성 기반 방법**: 정상 이미지에 인공 이상을 만들어 정상과 이상의 경계를 학습함. 그러나 인공 결함의 모습이 실제 결함과 충분히 비슷하지 않을 수 있음. 정상에서 너무 먼 가짜 이상만 쓰면 정상 영역의 경계가 느슨해져 미세 결함을 정상으로 포함할 수 있음.
- **임베딩 기반 방법**: ImageNet으로 사전학습된 CNN에서 정상 특징을 뽑고, 가우시안 분포, normalizing flow, normal memory 등으로 정상 특징 분포를 표현함. 테스트 특징이 이 분포 또는 기억한 특징과 얼마나 다른지로 이상을 판단함. 그러나 ImageNet과 산업 이미지의 분포 차이 때문에 특징 불일치가 생길 수 있고, 공분산 역행렬 계산이나 normal memory 최근접 탐색은 시간 또는 메모리를 많이 사용함.

SimpleNet은 임베딩 기반과 합성 기반의 장점을 결합함. 사전학습 특징을 그대로 쓰지 않고 특징 어댑터로 대상 도메인에 맞추며, 이미지가 아닌 특징 공간에서 잡음을 더해 이상 특징을 만듦. 마지막으로 복잡한 통계 모델 대신 작은 판별기를 학습함.

## 2. 관련 연구

### 2.1 복원 기반 방법

복원 기반 방법은 학습에 없는 이상 영역은 제대로 복원되지 않아야 한다는 생각을 사용함. 오토인코더나 GAN으로 정상 데이터를 부호화하고 복원하거나, 이미지 일부를 가린 뒤 복원하는 inpainting 방식이 사용됨. 입력과 복원 결과의 차이로 이상 지도를 만듦. 단, 이상이 정상과 국소 모서리 같은 구성 요소를 공유하거나 복호기가 강하면 이상도 잘 복원될 수 있음.

### 2.2 합성 기반 방법

합성 기반 방법은 이상이 없는 이미지에서 가짜 이상을 만듦. DRÆM은 합성한 out-of-distribution 무늬를 사용하고, CutPaste는 이미지 조각을 잘라 임의 위치에 붙임. 하지만 실제 결함은 매우 다양하고 예측하기 어려워 모든 실제 이상을 닮은 이미지 이상 집합을 만들기는 어려움. SimpleNet은 이 문제를 피하려고 이미지가 아니라 특징 공간에서 음성 샘플, 즉 이상 특징을 합성함.

### 2.3 임베딩 기반 방법

PaDiM은 특징을 다변량 가우시안 분포로 나타내고, PatchCore는 대표적인 정상 patch 특징을 normal memory에 저장함. 테스트 시 Mahalanobis 거리 또는 특징 거리를 사용함. Normalizing flow 계열은 정상 특징 분포를 가우시안으로 바꾸려 하지만 메모리 사용량이 클 수 있음. Teacher-student 증류 계열은 고정된 교사와 학생의 출력을 비교하므로 한 이미지가 두 네트워크를 모두 통과해야 함.

SimpleNet은 대상 데이터로 특징을 조정하고, 특징 공간에서 이상을 합성하며, 추론 시 하나의 흐름만 사용하도록 구성해 이 문제들을 줄이려 함.

## 3. 방법

SimpleNet은 특징 추출기 `F_φ`, 특징 어댑터 `G_θ`, 이상 특징 생성기, 판별기 `D_ψ`로 이루어짐. 이상 특징 생성기는 학습에만 쓰고 추론 때 제거함.

### 3.1 특징 추출기

학습 집합과 테스트 집합을 각각 `X_train`, `X_test`라고 함. 이미지 `x_i ∈ R^(H×W×3)`를 사전학습 네트워크 `φ`에 넣으면 여러 계층의 특징 지도가 나옴. 사용할 계층들의 집합을 `L`이라고 하고, 계층 `l`의 특징 지도를 `φ_{l,i} ∈ R^(H_l×W_l×C_l)`라고 함.

위치 `(h, w)`에서 patch 크기 `p`의 이웃은 다음과 같음.

`N_p^(h,w) = {(h', w') | h' ∈ [h-floor(p/2), ..., h+floor(p/2)], w' ∈ [w-floor(p/2), ..., w+floor(p/2)]}`  (식 1)

이 이웃 안의 특징을 adaptive average pooling으로 모아 지역 특징 `z_{h,w}^{l,i}`를 만듦.

`z_{h,w}^{l,i} = f_agg({φ_{h',w'}^{l,i} | (h',w') ∈ N_p^(h,w)})`  (식 2)

서로 다른 계층의 특징 지도는 가장 큰 특징 지도의 크기 `(H_0, W_0)`로 선형 resize한 다음 채널 방향으로 이어 붙임.

`o_i = f_cat(resize(z_{l',i}, (H_0,W_0)) | l' ∈ L)`  (식 3)

이를 간단히 `o_i = F_φ(x_i)`라고 씀. 논문의 기본 설정은 WideResNet-50의 두 번째와 세 번째 중간 계층을 사용함.

### 3.2 특징 어댑터

산업 이미지의 분포는 backbone을 사전학습한 데이터셋의 분포와 다를 수 있음. 따라서 어댑터 `G_θ`가 지역 특징 `o_{h,w}^i`를 대상 도메인에 맞춘 특징 `q_{h,w}^i`로 투영함.

`q_{h,w}^i = G_θ(o_{h,w}^i)`  (식 5)

어댑터는 완전연결층 또는 MLP로 만들 수 있음. 논문 실험에서는 편향 없는 단일 완전연결층이 좋은 성능을 보였음.

### 3.3 이상 특징 생성기

실제 결함 특징은 학습에 없으므로 분포를 추정하기 어려움. SimpleNet은 정상 특징 `q_{h,w}^i`에 독립 동일 분포 가우시안 잡음 `ε ∼ N(μ, σ²)`을 더해 가짜 이상 특징을 만듦.

`q_{h,w}^{i-} = q_{h,w}^i + ε`  (식 6)

저자들은 이 방식으로 학습하면 적응된 특징의 각 차원 표준편차가 더 일관되어 특징 공간이 더 조밀해진다고 관찰함.

### 3.4 판별기

판별기 `D_ψ`는 각 위치가 정상일 정도를 직접 예측함. 정상 특징에는 양의 출력을, 잡음을 더한 이상 특징에는 음의 출력을 내도록 학습함. 논문에서는 2층 MLP를 사용함.

### 3.5 손실 함수와 학습

각 위치의 절단된 L1 손실은 다음과 같음.

`l_{h,w}^i = max(0, t_h^+ - D_ψ(q_{h,w}^i)) + max(0, -t_h^- + D_ψ(q_{h,w}^{i-}))`  (식 7)

`t_h^+`, `t_h^-`는 과적합을 막기 위한 절단 기준이고, 기본값은 각각 `0.5`, `-0.5`임. 전체 목표는 모든 학습 이미지와 위치에서 이 손실의 평균을 최소화하는 것임.

학습 절차는 다음과 같음.

1. 사전학습 특징 추출기를 초기화함.
2. 정상 이미지를 넣어 지역 특징 `o`를 뽑음.
3. 어댑터로 `q`를 만듦.
4. `q`에 무작위 가우시안 잡음을 더해 이상 특징 `q_`를 만듦.
5. `D(q)`와 `D(q_)`로 손실을 계산함.
6. 특징 추출기는 gradient를 끊어 고정하고, 어댑터와 판별기만 Adam으로 갱신함.

### 3.6 추론과 점수

추론에서는 이상 특징 생성기를 버림. 테스트 이미지에서 적응된 특징 `q_{h,w}^i`를 만든 뒤, 판별기 출력의 부호를 바꾼 값을 이상 점수로 사용함.

`s_{h,w}^i = -D_ψ(q_{h,w}^i)`  (식 9)

모든 위치의 점수로 이상 지도 `S_AL(x_i)`를 만들고, 입력 이미지 크기로 보간한 후 경계가 매끄러워지도록 `σ=4`의 가우시안 필터를 적용함. 이미지 전체 이상 점수는 지도에서 가장 큰 점수임.

`S_AD(x_i) = max_(h,w) s_{h,w}^i`  (식 11)

## 4. 실험

### 4.1 데이터셋

주요 실험은 MVTec AD에서 수행함. 이 데이터셋은 제조 환경에서 나온 질감 5종과 물체 10종, 총 5,354장으로 구성됨. 학습에는 정상 이미지만 있고, 테스트에는 정상 및 여러 결함 유형의 이상 이미지가 있음. 결함 테스트 이미지에는 픽셀 수준 정답 위치도 제공됨.

이미지는 먼저 `256×256`으로 resize하고 `224×224`으로 중심 crop함. 데이터 증강은 사용하지 않음. 각 범주에 대해 그 범주의 정상 학습 샘플만으로 one-class 분류기 하나를 학습함.

CIFAR-10에서도 one-class novelty detection을 수행함. 한 범주를 정상으로 두고 나머지 범주를 새로움, 즉 이상으로 사용함.

### 4.2 평가 지표

- **I-AUROC**: 식 11의 이미지 이상 점수 `S_AD`로 이미지 수준 이상 탐지 성능을 측정함.
- **P-AUROC**: 식 10의 이상 지도 `S_AL`로 픽셀 수준 위치 찾기 성능을 측정함.

MVTec AD에서는 범주별 AUROC와 전체 범주의 평균 AUROC를 계산함.

### 4.3 구현 세부 설정

- 모든 backbone은 ImageNet으로 사전학습됨.
- ResNet 계열에서는 두 번째와 세 번째 중간 계층을 사용함.
- 기본 backbone: WideResNet-50.
- 특징 추출기 출력 차원: 1,536.
- 어댑터: 입출력 차원이 같은 편향 없는 완전연결층 1개.
- 이상 특징 생성기 잡음: `N(0, σ²)`, 기본 `σ=0.015`.
- 판별기: 선형층 - batch normalization - Leaky ReLU(기울기 0.2) - 선형층.
- 절단 기준: `t_h^+=0.5`, `t_h^-=-0.5`.
- Adam 학습률: 어댑터 `0.0001`, 판별기 `0.0002`.
- weight decay: `0.00001`.
- 범주별 학습 epoch: 160, batch size: 4.

### 4.4 MVTec AD 이미지 수준 이상 탐지

표의 각 값은 `I-AUROC% / P-AUROC%`임. 원문 표 1의 SimpleNet 결과를 옮기면 다음과 같음.

| 범주 | SimpleNet I-AUROC / P-AUROC |
|---|---:|
| carpet | 99.7 / 98.2 |
| grid | 99.7 / 98.8 |
| leather | 100 / 99.2 |
| tile | 99.8 / 97.0 |
| wood | 100 / 94.5 |
| 질감 평균 | 99.8 / 97.5 |
| bottle | 100 / 98.0 |
| cable | 99.9 / 97.6 |
| capsule | 97.7 / 98.9 |
| hazelnut | 100 / 97.9 |
| metal nut | 100 / 98.8 |
| pill | 99.0 / 98.6 |
| screw | 98.2 / 99.3 |
| toothbrush | 99.7 / 98.5 |
| transistor | 100 / 97.6 |
| zipper | 99.9 / 98.9 |
| 물체 평균 | 99.5 / 98.4 |
| 전체 평균 | **99.6 / 98.1** |

저자들은 15개 범주 중 9개에서 이미지 수준 최고 점수를 얻었다고 보고함. PatchCore의 I-AUROC 99.1%와 비교할 때 오류율이 0.9%에서 0.4%로 줄어, 오류를 55.5% 줄였다고 설명함.

### 4.5 위치 찾기

픽셀 수준 위치 찾기에서는 P-AUROC로 평가함. SimpleNet의 전체 평균 P-AUROC는 98.1%이며, 물체 범주 평균은 98.4%라고 보고함. 15개 범주 중 4개에서 가장 높은 점수를 얻었다고 보고함.

### 4.6 추론 시간

모든 방법을 Nvidia GeForce GTX 3080 Ti GPU 및 Intel Xeon E5-2680 v3 CPU가 있는 동일 하드웨어에서 측정했다고 설명함. SimpleNet은 77 FPS이며 PatchCore보다 약 8배 빠르다고 보고함.

### 4.7 Ablation study

**이웃 patch 크기.** patch 크기 `p`를 바꾸어 실험한 결과, 지역성 및 전역 맥락의 균형이 필요한 것으로 나타났고 기본값으로 `p=3`을 선택함.

**사용 계층.** WideResNet-50의 계층 조합 결과는 다음과 같음.

| 사용 계층 | I-AUROC% | P-AUROC% |
|---|---:|---:|
| 1 | 93.0 | 94.2 |
| 2 | 98.4 | 96.7 |
| 3 | 99.2 | 97.5 |
| 1 + 2 | 96.7 | 96.7 |
| 2 + 3 | **99.6** | **98.1** |
| 1 + 2 + 3 | 99.1 | 98.1 |

세 번째 계층만으로도 좋은 성능을 내지만, 두 번째 계층을 함께 쓰면 이득이 있어 `2+3`을 기본 설정으로 선택함.

**특징 어댑터.** 단일 FC 어댑터가 가장 좋았음.

| 모델 | I-AUROC% | P-AUROC% |
|---|---:|---:|
| SimpleNet 기본 | **99.6** | **98.1** |
| 복잡한 비선형 어댑터 | 98.3 | 97.2 |
| 어댑터 없음 | 99.2 | 97.9 |
| cross-entropy 손실 | 99.4 | 97.8 |

복잡한 어댑터는 과적합으로 테스트 결함에 대한 일반화 능력을 낮출 수 있다고 저자들은 해석함. 제안 손실은 cross-entropy보다 I-AUROC 0.2%p, P-AUROC 0.3%p 높았다고 보고함.

**잡음 크기.** `σ`가 크면 가짜 이상 특징이 정상 특징에서 너무 멀어져 결정 경계가 느슨해지고 false negative가 늘 수 있음. 반대로 너무 작으면 학습이 불안정하고 판별기의 일반화가 나빠질 수 있음. `σ=0.015`가 균형을 이루어 가장 좋은 성능을 냈다고 보고함.

**backbone.**

| Backbone | I-AUROC% | P-AUROC% |
|---|---:|---:|
| ResNet-18 | 98.3 | 95.7 |
| ResNet-50 | 99.6 | 98.0 |
| ResNet-101 | 99.2 | 97.6 |
| WideResNet-50 | 99.6 | 98.1 |

backbone 선택에 따른 결과는 대체로 안정적이었다고 하며, WideResNet-50은 PaDiM 및 PatchCore와 공정하게 비교하기 위해 선택했다고 설명함.

### 4.8 One-Class Novelty Detection

CIFAR-10에서 각 범주를 차례로 정상으로 두고 나머지를 새로움으로 탐지함. 모든 방법은 ImageNet 사전학습을 사용해 비교함. SimpleNet의 I-AUROC는 86.5%로, 표에 제시된 비교 방법 중 최고 결과와 같다고 보고함.

## 5. 결론

본 논문은 비지도 이미지 이상 탐지와 위치 찾기를 위한 단순하고 효율적인 SimpleNet을 제안함. SimpleNet은 학습과 적용이 쉬운 단순한 신경망 모듈로 구성되고, MVTec AD에서 당시 기존 방법과 비교해 높은 성능 및 빠른 추론 속도를 보였다고 저자들은 결론지음. 이 방법은 이상 탐지 연구와 산업 적용 사이의 간격을 줄이는 관점을 제공함.
